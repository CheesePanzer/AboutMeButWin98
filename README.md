# AboutMeWeb - Windows 98 Variant

A playful Windows 98-style portfolio based on [98.css](https://jdan.github.io/98.css/).

## Cloudflare Pages

- Framework preset: None
- Build command: leave empty
- Output directory: `website-win98` when deploying from the resume directory, or `/` when this folder is the repository root

The 98.css stylesheet is loaded from unpkg. Local `styles.css` adds the desktop layout and responsive behavior.
